# tsds-install

Internal `npm install` command used by `ts-dev-stack`.

## Install

```bash
npm install --save-dev ts-dev-stack
```

## Use

```bash
npx tsds install
```

Arguments after `install` are passed to npm. Add `--dry-run` to check command
selection without installing. See the
[ts-dev-stack documentation](https://www.npmjs.com/package/ts-dev-stack) for
project setup.
